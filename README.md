# GramsevaMitra

**Your private toolkit for documents, photos, and everyday work — built for India.**

## Vision

GramsevaMitra helps people get more done without depending on expensive offices or confusing software.

- **Scan and save** important papers on your phone  
- **Convert** scans into editable Word / Excel files (Pro)  
- **Edit photos and short videos** for exams, forms, and sharing  
- **Work offline** when the network is weak  
- **Keep files private** on your device whenever possible  

Free tools stay useful forever. Pro unlocks advanced AI help when you need it — paid simply with UPI or cards.

## What’s in this project

| Folder | What it is (in plain words) |
|--------|-----------------------------|
| `apps/` | The main website / phone app |
| `assets/` | App logo and brand pictures |
| `android/` | Files used to build the Android phone app |
| `functions/` | Secure cloud helpers (login, payments, AI) |
| `docs/` | Simple project notes and vision |
| `packages/` | Shared building blocks used across the app |
